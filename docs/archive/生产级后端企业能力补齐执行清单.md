## 1. 企业后端治理能力

- [x] Service/scoped API key：实现服务账号式 API key 的创建、列表、撤销、哈希存储、scope 校验与审计。
  - 验收：企业模式下可颁发 scoped key；key 只能访问授权 KB/权限；撤销后立即失效；全局 `LIGHTRAG_API_KEY` 仍按现有 legacy 策略处理。
  - QA：新增并通过 API 路由测试、metadata store contract 测试。
- [x] 配额与请求限流：实现 user / tenant / API key 级请求限流与基础 quota 计数。
  - 验收：超过配置阈值返回 429；写入 `rate_limited` 或 `quota_exceeded` 审计；默认不启用时不影响现有行为。
  - QA：新增并通过 config/route 级测试。
- [x] Prometheus `/metrics`：实现基础 Prometheus 文本端点。
  - 验收：返回 `text/plain` Prometheus 指标；至少包含 KB、document、job、enterprise audit/limit 相关基础计数或状态。
  - QA：新增并通过 API endpoint 测试，手工请求验证输出。
- [x] SSO/OIDC/SAML：明确当前 API-only 上线闭环不纳入 SSO/OIDC/SAML，并在文档中降级为后续安全接入项。
  - 验收：若实现 OIDC，必须有配置校验、登录跳转/回调、用户映射与测试；若当前范围无法安全接入，需在文档明确降级为未纳入本轮上线。
  - QA：配置解析测试、回调处理测试或明确的延期说明。
